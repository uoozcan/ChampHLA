# Benchmark Analysis - 2026-04-01

## Scope

This note summarizes the current fixture benchmark produced from:
- `tests/fixtures/benchmark_config.yaml`
- `bin/hla_benchmark.py`
- output directory: `analysis/latest_benchmark/`

The fixture benchmark is small and synthetic, so conclusions here are directional rather than publication-level. Its main value is validating whether the benchmark architecture exposes scientifically meaningful signals.

## Main Findings

### 1. The weighted ensemble is already useful in mixed-confidence WGS settings
In `method_comparison.tsv`, weighted consensus improves WGS overall correct-call rate from `0.8333` under the majority-vote baseline to `1.0`.

Interpretation:
- the confidence-weighted model is doing more than reproducing majority vote,
- the gain is not global noise; it is concentrated in a conflict setting where one tool is stronger for a specific locus.

### 2. The gain is localized rather than uniform
In `per_gene_gain.tsv`, the WGS benefit is concentrated at gene `C`:
- weighted consensus: `1.0`
- majority vote: `0.5`
- best single tool: `1.0` (`SpecHLA`)

Interpretation:
- the ensemble is currently learning to avoid a majority-vote failure,
- but it is not yet outperforming the best single tool,
- which means the present benchmark supports a claim of safer aggregation, not yet a claim of universally superior accuracy.

### 3. RNA-seq remains the harder regime
Weighted consensus matches the strongest RNA-seq single-tool baseline at `0.8333`, but does not improve on it.

Interpretation:
- the current RNA-seq tool diversity and confidence signals are not yet strong enough to create a gain over the best caller,
- but the benchmark correctly preserves the stronger RNA-seq caller rather than degrading it.

### 4. Calibration differences are real and modality-specific
In `confidence_calibration_summary.tsv`:
- OptiType WES: mean confidence `0.985`, observed accuracy `1.0`, Brier `0.0003`
- OptiType WGS: mean confidence `0.985`, observed accuracy `0.8333`, Brier `0.1602`
- OptiType RNA-seq: mean confidence `0.895`, observed accuracy `0.6667`, Brier `0.23`
- ArcasHLA RNA-seq: mean confidence `0.7533`, observed accuracy `0.8333`, Brier `0.0555`

Interpretation:
- raw confidence is clearly not transferable across modalities,
- the benchmark now supports the project's core argument for calibration-aware weighting,
- and it already shows that sidecar read-support can produce a usable confidence signal.

### 5. Ambiguity-aware evaluation is adding real information
In `ambiguity_summary.tsv`:
- SpecHLA WES/WGS remains `1.0` at exact 2-field rate,
- but drops to `0.0` at exact 3-field rate,
- whereas OptiType WES remains `1.0` at both 2-field and 3-field.

In `method_ambiguity_summary.tsv`:
- MajorityVote WGS is `0.8333` at exact 2-field and `0.8333` at exact 3-field,
- WeightedConsensus WGS is `1.0` at exact 2-field and `1.0` at exact 3-field.

Interpretation:
- resolution-aware reporting is necessary,
- a single exact-match metric would hide important caller behavior,
- and the benchmark now shows that the weighted ensemble preserves its WGS gain even when evaluated at 3-field resolution in this fixture.

### 6. IMGT/HLA version propagation is working
The current benchmark reports IMGT/HLA version `3.59.0` in:
- `reference_metadata.tsv`
- `benchmark_metadata.json`
- `harmonized_benchmark_rows.tsv`

Interpretation:
- database versioning is no longer only a documentation promise,
- it is now part of the benchmark output contract.

### 7. Abstention is wired, but current fixtures are too easy
In `abstention_tradeoff.tsv`, increasing `min_support` above `0.55` reduces call rate without improving accuracy.

Interpretation:
- abstention logic is functioning,
- but the current fixture benchmark is too small and too easy to characterize its real value.

### 8. Discordance tagging is functioning at the expected minimal level
`discordance_summary.tsv` currently reports one cross-modality `dna_rna_discordance` event.

Interpretation:
- the taxonomy wiring is real,
- but the current dataset is too small for biological interpretation claims.

## What The Current Benchmark Supports Scientifically

The current benchmark supports these claims:
- the framework can learn benchmark-derived confidence weights,
- weighted consensus can outperform strict majority vote in conflict cases,
- calibration is modality-specific and should not be treated as a raw cross-tool quantity,
- ambiguity-aware evaluation changes interpretation of tool performance,
- IMGT/HLA versioning and benchmark provenance are now machine-readable.

## What It Does Not Yet Support

The current benchmark does not yet support these stronger claims:
- weighted consensus is better than the best single caller overall,
- abstention improves real-world precision on challenging cohorts,
- discordance taxonomy captures biologically meaningful structure beyond toy validation,
- G-group and P-group analyses are informative at scale.

## Recommended Next Analysis Steps

1. Run a larger holdout cohort with orthogonal truth.
2. Add more RNA-seq caller diversity if the goal is to beat the best RNA-seq single tool.
3. Add truth/call inputs with explicit G-group or P-group encodings.
4. Add confidence-stratified error analysis by gene and modality.
5. Quantify whether WGS gene `C`-like improvements recur in real cohorts or are fixture-specific.
6. Expand method-level ambiguity analysis onto larger holdout cohorts with more three-field truth coverage.
